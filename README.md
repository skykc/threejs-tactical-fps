Depot 9 — a round-based tactical FPS in the browser, built on three.js. You attack with the bomb against four defender bots across an industrial depot: two bombsites, three lanes, a buy menu between rounds, and gunplay where stopping to aim beats spraying. First to 5 rounds takes the match.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
